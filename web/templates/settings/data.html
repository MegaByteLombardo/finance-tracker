Database snapshots and disaster recovery

Offline Restore Instructions

For data safety and filesystem consistency, restoring a database snapshot cannot be initiated while the web service is actively running. Use the command line: 

docker compose stop
docker compose run --rm app restore --file <snapshot-filename>
docker compose up -d

Refer to docs/operations.md for complete operational procedures and retention details.
